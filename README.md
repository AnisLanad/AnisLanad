# Anis Lanad

Développeur mobile et back-end basé à Alger. Je conçois des applications mobiles (Flutter, Kotlin) et les API qui les alimentent (Django, Firebase), principalement pour des outils métier : CRM, gestion commerciale, e-commerce.

## Stack

- **Mobile** : Flutter / Dart, Kotlin (Android natif)
- **Back-end** : Django, Django REST Framework, Flask, Firebase (Firestore, Auth, Cloud Functions)
- **Données et outillage** : MySQL, Docker, scikit-learn
- **Autres** : Java EE (EJB), TypeScript
